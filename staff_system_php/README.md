# Staff Database Management System
Built for XAMPP (PHP 8+, MySQL, Apache)

## Setup Instructions
1. Move the `staff_system_php` folder to your XAMPP `htdocs` directory (`C:\xampp\htdocs\`).
2. Open phpMyAdmin (`http://localhost/phpmyadmin`).
3. Create a database named `staff_db`.
4. Import `database.sql` into the `staff_db` database.
5. Access the app at `http://localhost/staff_system_php`.

## Accounts
- **Admin**: `admin@example.com` / `admin123`
- **Staff**: Register via the Staff Portal, then activate the account via the Admin Dashboard before logging in.
